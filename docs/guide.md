# スロキー 使い方ガイド

> パチスロ情報を集めて・見て・分析する社内ツールです。

---

## このツールの目的

**スロキー（SLOKEY）** は、パチスロに関する情報を一か所に集めて、チームで共有・分析するためのツールです。

- ウェブ上に散らばっている機種情報・ホール情報・打ち手の声を整理してストック
- 「どの機種が今熱いか」「どんな情報が不足しているか」をデータで把握
- チームで気になった情報を投稿・いいねして質を上げていく

企画のネタ出し、機種の情報収集、ホールの動向把握など、日常業務の参考にしてください。

## 画面の構成

画面下部に4つのタブがあります。

| タブ | できること |
|------|-----------|
| **投稿** | 集まった情報を読む・いいねする |
| **追加** | 新しい情報を投稿する |
| **まとめ** | カテゴリ別の投稿数や傾向を俯瞰する |
| **リサーチ** | 機種別・カテゴリ別に深掘り分析する |

---

## 投稿の種類（カテゴリ）

情報はカテゴリで分類されています。読むときの参考に。

| カテゴリ | 内容 |
|---------|------|
| 機種情報 | 天井・設定判別・機械割など攻略系 |
| ゲーム性評価 | 面白い/つまらない・打感・演出の好き嫌い |
| お店狙い目 | 高設定が入りやすい店・タイミングの情報 |
| 演出・表現 | 演出の法則・好きなシーン・演出のデキレ疑惑など |
| 業界情報 | ホール・メーカー・規制など業界動向 |
| 昔の機種 | 旧機種の思い出・伝説エピソード |
| 版権ネタ | 原作・キャラ・楽曲に関する話題 |
| 勝＆負エピ | 実戦エピソード（勝ち・負け体験談） |
| その他雑談 | 上記に当てはまらない話題 |

## 基本的な使い方

### 情報を読む（投稿タブ）

- 一覧表示されている投稿をスクロールして読む
- 上部のカテゴリボタンで絞り込める
- 気になった投稿は **♥ ボタン** でいいね
- 投稿内のURLをタップすると元記事に飛べる（URLがない投稿もある）

### 情報を投稿する（追加タブ）

1. 「新規投稿」ボタンをタップ
2. カテゴリ・機種名・タイトル・本文を入力
3. URLがあれば貼り付けると本文を自動取得してくれる
4. 投稿ボタンで送信

気軽に使ってください。短い一言でもOKです。

## データ分析のやり方（リサーチタブ）

「リサーチ」タブには5つのモードがあります。

---

### 絞り込み

機種名・カテゴリを選んで投稿を絞り込んで読む。
気になる機種の情報だけまとめて見たいときに使う。

---

### ランキング

機種ごとに投稿数・いいね数・品質スコア・直近2週間の投稿数を一覧表示。

- **投稿数ソート** → 情報量が多い（=注目度が高い）機種がわかる
- **いいねソート** → チームが「使える」と評価した情報が多い機種がわかる
- **品質ソート** → 信頼度の高い情報が集まっている機種がわかる
- **直近2週間ソート** → 今まさに話題になっている機種がわかる

新台導入後の盛り上がり確認や、どの機種の情報収集を強化すべきかの判断に使う。

---

### ギャップ表

機種 × カテゴリのマトリクス表。情報が不足しているセル（赤色）が一目でわかる。

- **赤** → 情報なし（収集の優先度が高い）
- **黄** → 1件のみ（もう少し集めたい）
- **緑** → 2件以上（ある程度揃っている）

「この機種のお店狙い目情報が全然ない」「ゲーム性評価が偏っている」といった気づきに使う。

---

### 機種分析

特定機種の「良いところ・悪いところ」をまとめて確認できる。

ドロップダウンから機種を選んで「分析する」ボタンを押すだけ。
分析データがない機種は **📊 未分析（N件）**、情報が増えて再評価が必要な機種は **⚠️ +N件追加あり** と表示される。

分析は手動で随時更新しているものです（AI自動生成ではありません）。

---

### チャット

AIと会話しながら特定の機種やカテゴリについて深掘りできる機能。
※現在準備中の場合あり。

## フィードバックについて

このツールはまだ発展途上です。
使っていて「こんな情報が欲しい」「この機能が使いにくい」と感じたら教えてください。

**フィードバックの伝え方**
画面右下の 💬 ボタンからいつでも送れます。種類（機能要望・バグ報告・その他）を選んで、内容を入力して送信するだけです。名前は省略可能ですが、直接やりとりしたい場合は記入いただけると助かります。送った内容は管理者のみ確認できます。

## よくある質問

**Q. 投稿した情報は全員に見えますか？**
A. はい、ツールを開いている全員が見られます。

**Q. 投稿を間違えた場合は？**
A. 自分の投稿は削除できます。一覧の右上にあるメニューから操作してください。

**Q. 情報の信頼性はどうやって判断する？**
A. 投稿には品質スコア（情報Lv.1〜3）が付いている場合があります。Lv.3が最も信頼度が高いです。また、いいね数も参考になります。

**Q. スマホとPCで内容は同じですか？**
A. 同じデータを見ています。どちらで開いても常に最新の情報が表示されます。
