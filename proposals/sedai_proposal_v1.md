# 「世代 ―継承の炎―」新機種企画提案書 v1.0

## コアコンセプト

**「一人では届かない。でも、意志は続く。」**

1回のATが1世代。世代を重ねるほど物語が深まり、積み上げた意志が最後に爆発する。
RPGの「プレイするほど世界が豊かになる」感覚をパチスロへ。

---

## 設計の3本柱

### 1. 感情設計：世代交代ループ
- 1セット消化 = 1世代が終わる
- AT終了時「継承演出」が流れ、次の世代が立ち上がる
- 「また負けた」ではなく**「次の世代へ繋いだ」**になる感情設計
- 負けをポジティブに転換する唯一の構造

### 2. 継承の儀（業界初）
- AT消化中、赤7揃いで発動（ミリゴZ-ZONEを応用）
- 3択の選択：**技の継承 / 絆の継承 / 力の継承**
- 選んだ内容が次世代ATの性能に直結
- プレイヤーが物語を選ぶ台 = 誰も同じ体験をしない

### 3. 宿敵弱体化ゲージ（1セッション完結）
- ATを重ねるほど宿敵が弱体化する
- ゲージMAX + 皇帝の力 + 継承コンプリートで「決戦AT」解放
- 「今日が決戦だ」という感動を1セッション内で完結させる

## ゲームフロー

```
通常時（4ステージ）
　↓ 周期100G毎にCZ「英雄の試練」
世代AT（1世代50G / 純増4.0枚/G）
　↓ 赤7揃いで「継承の儀」発動（3択選択）
　↓ ストック残 → 世代ループ（世代重ね）
　↓ 3世代以上
英雄連合（継続率75% / 純増6.5枚/G）
　↓ AT終了後5G「英雄の残照」（引き戻し）
　↓ 宿敵弱体化MAX + 皇帝の力 + 継承コンプリート
決戦AT「世代の決着」（純増8.0枚/G / MY約3,500枚）
```

## 業界初ポイント（3点）

1. **世代交代ループ演出**：ATループ = 世代交代。負けが物語に変わる
2. **継承の儀（AT中の3択選択）**：プレイヤーが能動的に物語を選ぶ
