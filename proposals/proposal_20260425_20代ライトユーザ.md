# 新機種ゲーム性提案書

## 1. 市場の現状と課題

現行スマスロ市場を分析すると、20代ライトユーザーを疎外する設計が目立つ。**自力感・択あて過多問題**：カバネリの自力上乗せ4GやヨルムンガンドのCZ2部構成は、「外した絶望感」がライトユーザーの離脱を加速させている。**コイン単価の高騰**：吉宗・アクダマドライブはコイン単価4.5円超えで20代の投資許容範囲を超えつつある。**やめ時設計の欠如**：虚構推理のみが「ボーナス後に強制フェーズ突入」設計でやめにくくしているが、演出テンポ問題がある。市場には「プレイヤーが判断を求められず、システムが自動的に次の展開へ誘導し続ける台」が存在しない。

## 2. コンセプト

**キャッチ：「ループから抜け出せない、電脳の迷宮へようこそ」**

タイムリープ × 電脳ダイブをゲーム設計のコアに据えた近未来アクションATスロット。プレイヤーは「タチコマと共に電脳空間を探索するSection9エージェント」として、ループするたびに情報が積み重なり強くなる感覚を体験する。東京リベンジャーズ的な「タイムリープ→再挑戦→積み重ね」の感情体験を攻殻機動隊の世界観で実現。択あて・自力感を完全排除し、気づいたらやめられない状態を作る。

## 3. ゲームフロー概要

```
通常時（電脳哨戒モード）
│  ゾーン：150G・300G・500G（設定差大）
│  レア役 / 特定演出 → CZ「電脳ダイブ」（20G）
│
├─ CZ失敗 → 電脳ポイント(EP)として蓄積（持ち越し可能）
│           EP 500pt到達で次CZへ優遇抽選
│
└─ CZ成功 → AT「Section9 Operation」
             純増：3.5枚 / 1セット30G
             │
             ├─ ミッション継続（継続率60〜80%・設定差）
             │   └─ 300枚確定×継続 → 1000〜3000枚レンジ
             │
             └─ タイムリープ発動（AT中 約1/2500・設定差大）
                  「ループ」演出 → 純増5.5枚に強化

AT終了後
└─ 「次の作戦命令受信中」演出100G継続
   ※CZ優遇状態でやめにくい仕組み

天井：通常700G（EP蓄積量で600Gに短縮）
```

## 4. 推奨スペック

- **機械割**：設定1 / 97.5%、設定4 / 103.5%、設定6 / 113.5%
- **AT純増**：通常3.5枚、タイムリープ時5.5枚（スマスロ）
- **コイン単価**：3.2〜3.5円（20代でも続けやすいレンジ）
- **天井**：通常700G（EP蓄積で600G短縮）
- **初当り**：設定1 / 1/280、設定6 / 1/210（ライト向けに軽め）
- **ATセット**：1セット30G・約300枚確定（短めで快感頻度を上げる）
- **継続率**：60〜80%（設定差・セット移行で変動）
- **タイムリープ**：AT中 約1/2500（設定6は約1/1200）

## 5. 差別化ポイント

1. **「CZ失敗」がロスにならないEP蓄積設計**
   ヨルムンガンドで頻発した「1500G回してCZ0回」への絶望感を解消。失敗するたびにEPが積み上がり「次は必ず近づいている」視覚化でライトユーザーの離脱を防ぐ。目安：CZ失敗1回で100EP、EP500ptで天井短縮効果。

2. **択あて・自力感を完全排除した「自動連鎖AT」**
   タイムリープ演出でプレイヤーは判断を一切求められない。カバネリの「自分で引く感」ではなく「システムが次に連れていく感」を徹底。東京リベンジャーズの「また戻れる」感覚をシステムに落とし込む。

3. **「次のミッション告知」によるやめ時の消去**
   AT終了後100Gは「次の作戦命令受信中」演出が流れ続け、タチコマのセリフで「次のミッションまであと○G」と常に前を向かせる。虚構推理の強制フェーズ突入設計を参考に、通常時に戻った感覚を与えない。

4. **設定判別を「タイムリープ頻度」一本に集約**
   ミリオンゴッドの偶数設定優遇・ガンダムユニコーンの複雑な段階設計に対し、「タイムリープ演出が多ければ高設定」という一本化した判断基準。初心者でも直感的に分かる。

5. **タチコマ主役設計によるIP入口の拡大**
   素子・バトーはサブに回し、タチコマの愛嬌ある演出でNetflix世代の20代（SAC_2045認知層）を取り込む。タチコマの哲学的セリフが演出の深みを生み、知らない層でも「何かキャラが面白い」と引き込む。

## 6. 想定プレイヤー体験

着席すると「電脳哨戒開始」のアニメ風カットインが走り、タチコマの声で「今日の任務を始めよう」とアナウンスされる。300G付近でゾーン演出が始まりスムーズにCZへ。CZを失敗しても「電脳ポイント積み上げ中」のゲージが画面端で溜まっていく様子が見えるため、「無駄じゃなかった、続けよう」という感情が生まれる。ATに入れば30Gのセットが淡々と積み重なり、「ミッション継続」演出のたびに続きが気になってしまう。AT終了後も「次の作戦命令が届いています」と言われ席が立ちにくい。そして突如「タイムリープ発動」の演出が画面全体に走り、純増が5.5枚へ強化される瞬間に打ち手がざわめく。友人と来た20代が「これ気づいたらずっと打ってた」と口コミで広がるような、押しつけ感のない中毒設計。

## 7. リスクと対策

1. **「やめ時がない」設計がヘビーユーザーに嫌われる可能性**
   対策：AT終了後の「次のミッション演出」はOFF設定を用意。ライト層はON・玄人はOFFで共存。演出OFFでも期待値は変わらない設計にする。

2. **低設定での体験が薄くなるリスク**
   タイムリープ確率に設定差を集中させるため、低設定では「ループが来ない」体験が続く懸念がある。対策：EP蓄積・AT継続率の設定差は最小限（設定1〜6で20%以内の差）にとどめ、AT自体の楽しさは設定不問で確保。「タイムリープだけが設定差」という設計原則を守ることで、低設定でも打感を維持する。

3. **攻殻機動隊IP版権のコストと世代ギャップ**
   40代以上のオリジナル層と20代のSAC_2045層で温度差がある。対策：タチコマをメインに据え、全世代の入口を「かわいいタンク型ロボット」に統一。深みが欲しい層向けに素子のセリフ・哲学的演出をプレミア枠として残す。
