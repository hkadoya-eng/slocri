# 新機種ゲーム性提案書
## 「祟り神の章」〜物語と出玉が交差するスロット〜

---

## コンセプト一言

**「倒した相手を、後から理解する。」**

普通ATで祟り神を「戦って倒す」台。
特別ATでその祟り神の「なぜそうなったか」が分かる台。
2つのATが独立していながら、感情で交差する。

---

## なぜこれが新しいのか

| 従来機 | 本提案 |
|---|---|
| ATは「出玉を取る場所」 | ATは「出玉を取る場所」＋「物語が進む場所」 |
| リピート理由は設定・期待値 | リピート理由は「続きが見たい」 |
| 全員が同じ体験 | 章のランダム順で体験が変わる |
| 1回の来店で完結 | 複数回来店で完成する |

---

## プレイヤー感情マップ（ここで楽しませ、ここで揺さぶる）

---

### ① 来店・着席

**楽しませる：自分の進捗が出迎えてくれる**

```
スマスロカードを挿す
→「2章・3章クリア済み　加護×2所持」が表示される

前回の自分が残した痕跡が
今日の期待感に変わる瞬間
```

**揺さぶる：「今日はどの章が来るか」という予感**

---

### ② 通常時（SP蓄積フェーズ）

**楽しませる：小さな積み上げの快感**

```
レア役が来た → SP+10
             → 天井がまた少し縮んだ

目に見えないところで
自分の資産が積み上がっていく感覚
```

**揺さぶる：特別AT抽選への期待がじわじわ高まる**

---

### ③ 普通AT（バトル型）

**楽しませる：3段階で盛り上がる設計**

```
1〜10G   ザコ戦     ほぼ勝てる・ウォームアップ
11〜20G  中ボス戦   勝率60〜70%・本番感
21〜40G  ボス戦     勝率40〜50%・「頼む倒れてくれ」
```

**揺さぶる：勝敗の一喜一憂**

- 勝った → 「よし、継続だ！」
- 負けた → 「あと一息だったのに…悔しい」

> ★ここで重要な設計：
> 倒した祟り神は「敵」として記憶される。
> この認識が後で逆転することが、最大の感動になる。

---

### ④ 特別AT突入の瞬間

**楽しませる：「どの章が来るか」のランダム感**

```
特別ATのロゴが出る
→「今日は何章だろう」

まだ見ていない章 → 「新しい話が見られる！」
すでに見た章    → 「今度は別の視点で観よう」
```

**揺さぶる：まだ見ていない章が来た瞬間の興奮**

---

### ⑤ 章の中で（オムニバス設計）

**楽しませる：同じ事件を別の目で見る**

```
第1章：祟られた村人の視点
　　　「なぜ自分たちが祟られたのか分からない」

第2章：封じた僧侶の視点
　　　「封じるしかなかった、あの日の決断」

第3章：祟り神の家族の視点
　　　「あの人がなぜ祟り神に…」

第4章：祟り神自身の記憶（断片）
　　　「守りたかっただけなのに」

第5章：全視点が収束する
第0章：なぜ祟り神になったか、最初の記憶（真実）
```

**揺さぶる：感情の逆転**

```
「普通ATで倒したあいつ、こういう事情だったのか」

敵  →  理解できる存在

この逆転が起きる瞬間が
このゲームの最大の感情体験
```

そして章は**クリフハンガーで終わる**。
「続きが気になる」が次回来店の理由になる。

---

### ⑥ 加護獲得（章クリアのたびに）

**楽しませる：コレクションが積み上がる達成感**

```
章クリア → 「祟り神の加護」を1つ獲得

加護1個：「まだ弱い」
加護2個：「半分来た」
加護3個：「あと1個だ」
加護4個：「全部揃えた。第5章に行ける」
```

**揺さぶる：加護が揃った瞬間の達成感と第5章への期待**

| 章 | 獲得する加護 | 第5章での効果 |
|---|---|---|
| 第1章 | リプレイの力 | リプレイ成立でAT抽選が走る |
| 第2章 | ベルの力 | 打順ベル成立で上乗せ抽選 |
| 第3章 | 選択の力 | 毎セット2択チャレンジが発生 |
| 第4章 | 魂の力 | セット継続率が底上げされる |

---

### ⑦ 第5章AT（加護4個所持時）

**楽しませる：同時多発で何かが起き続ける**

```
リプレイが来た     → AT抽選が走る！
ベルが成立した     → 上乗せ抽選！
セットが始まった   → 2択チャレンジ！
継続率も底上げ     → なかなか終わらない

「何かが次々と起きてる、忙しい！」

これが「超楽しい」の設計的な正体
```

**揺さぶる：1500枚が現実的に見えてくる緊張感**

```
「これは今日、いけるんじゃないか」
```

加護が少ない状態で来ると同じ第5章でも体験が薄い。
だから「また章を集めに来る」動機が生まれる。

---

### ⑧ 第0章（全章コンプリート者限定）

**楽しませる：「自分だけが辿り着いた場所」という感覚**

```
「真の章が解禁されました」

全視点が交差して
真実が一枚の絵として完成する

なぜ村人は祟られたのか
なぜ僧侶は封じるしかなかったのか
なぜ家族は気づけなかったのか
なぜ祟り神はそうなったのか

全部が繋がる
```

**揺さぶる：成仏チャレンジの極限**

```
「頼む、成仏してくれ」

成功 → 1500枚 ＋「救えた」という感動
失敗 → 100枚  ＋「また来て救いに来よう」
```

失敗しても「終わり」ではなく「また来たい理由」に変わる。
なぜなら物語はまだ終わっていないから。

## 差別化の核心（3点）

**① 「倒した敵を後から理解する」感情逆転設計**
普通ATで敵として戦った相手が、特別ATで共感できる存在になる。
この感情の逆転は業界に前例がない。

**② DQ4型オムニバス章システム（業界初）**
ランダム順に届く5つの視点。全部集まって初めて真実が見える。
「俺は3章から入った、お前は？」という会話がホールで生まれる。

**③ 加護の持ち越しで「第5章が超楽しくなる」設計**
章をクリアするほど第5章のATが強化される。
来るたびに体験が豊かになる、来店価値の積み上げ設計。

---

## 議論したい論点

**Q1: 第0章クリア後のリセット設計**
また最初から章を集め直すループにするか、別の祟り神のストーリーに移るか。

**Q2: 加護は全台共通か、スマスロ個人管理か**
個人管理の方が「自分の加護」感が強い。

**Q3: IPはオリジナルを推奨**
「この台でしか見られないストーリー」の価値を最大化するには
既存IPより、台専用のオリジナルIPが適切。
