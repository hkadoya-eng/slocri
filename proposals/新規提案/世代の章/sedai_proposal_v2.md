## コアコンセプト：世代交代ループとは何か

### Re:ゼロとの対比で理解する

| 軸 | Re:ゼロ | 世代 ―継承の炎― |
|---|---|---|
| 失敗の意味 | タイムリープ（リセット） | 継承（積み上げ） |
| プレイヤーの感情 | 「また失敗した…でも次へ」 | 「この意志を次世代に渡した」 |
| 設計思想 | 失敗前提ループ | 積み上げ前提ループ |
| ゲームオーバー感 | あり（リセット感） | なし（継続感） |

**「負けても前進感がある設計」は業界に存在しない。これが世代の核心。**

### 感情の山場設計（6段階）

1. 通常時：「継承ポイントが貯まってきた…」（積み上げ感）
2. CZ：「今世代で英雄になれるか」（緊張）
3. AT継承の儀：「何を次の世代に残すか」（能動的な選択）
4. 英雄連合到達：「3世代繋いだ」（達成感）
5. 決戦AT発動：「ついにこの日が来た」（最大の興奮）
6. 宿敵討伐演出：「積み上げた意志が実った」（感動）

## 世界観（オリジナルIP）

### 設定

- **舞台**：魔王「イグナール」が1000年間支配し続ける世界
- **主人公**：代々受け継がれる「英雄の末裔」。1人では魔王に届かない
- **宿敵**：不死の魔王「イグナール」。倒されるたびに蘇り、再び世界を闇に包む
- **プレイヤーの役割**：「英雄の系譜を繋ぐ者」。1世代の戦いを次世代へと繋ぐ

### 物語の骨格

```
第1世代の英雄が魔王に挑む → 力尽きる
「継承の炎」を次の英雄に渡す

「速さ」と「絆」を次へ渡す
第3世代…積み重なった意志が結晶化
英雄連合「かつての英雄たちが集う」
決戦 ── 1000年ぶりに宿敵イグナールが倒れる
```

## 通常時の設計

### 何をする台か（3行で）
> 100G周期でCZが来る。失敗しても継承ポイントが貯まる。貯まるほど天井が短くなり、高確モードで連続CZが来る。

### ステージ4種

| ステージ | 状態 | 演出 |
|---|---|---|
| 荒野 | 通常 | 魔王の影が遠くに見える |
| 城下町 | 高確示唆 | 英雄の噂が流れ始める |
| 王都 | 前兆・CZ高確率 | 英霊が現れ始める |
| 黄金都市 | AT超高確率 | かつての英雄たちの残影 |

### 継承ポイントシステム

| 到達pt | 効果 |
|---|---|
| 50pt | 天井100G短縮（600G→500G） |
| 100pt | 天井200G短縮（最短400G） |
| 200pt | CZ突破率大幅UP |
| 300pt | 高確モード「英霊の導き」発動 |

### 高確モード「英霊の導き」
- 継承ポイント300pt到達で発動
- 連続CZ状態。CZ失敗しても次の周期CZが20G後に来る
- 「貯めれば貯めるほど有利になる」具体的な実感

## AT「世代AT」の遊び方

### 継承の儀（3択・具体的な効果）

AT中に**赤7揃い**で発動。何を次世代に残すかをプレイヤーが選ぶ。

| 選択肢 | 次世代への具体的な効果 |
|---|---|
| **速さの継承** | 次セット開始から10G高確（レア役確率1.5倍） |
| **深さの継承** | 宿敵弱体化ゲージが通常の3倍速で貯まる |
| **絆の継承** | AT終了後の引き戻し「英雄の残照」5Gが確定発動 |

### 選択の意味
- 「速さ」→ 短期でループ率を高めたいとき
- 「深さ」→ 決戦ATを目指すとき
- 「絆」→ AT終了後の引き戻しを確保したいとき

**3択すべてを選び揃えると「継承コンプリート」達成 → 決戦AT解放条件の1つ**

### ストック4種（ループ率）

| ストック | GGループ率 |
|---|---|
| 一代の力 | 20% |
| 二代の力 | 40% |
| 三代の力 | 60% |
| **皇帝の力**（レア） | **80%** |

## 英雄連合（3世代ループ達成の報酬）

### 発動条件
- 世代AT 3回以上ループ達成（3世代の英雄が揃う）
- 特定の継承組み合わせで確率UP

### 性能
- 継続率：**75%**
- 純増：**6.5枚/G**
- 期待枚数：1,000〜1,500枚

### 演出設計
- 第1・第2・第3世代の英雄が「連合」して戦う演出
- 各世代の継承選択が演出に反映される（速さを継いだ世代は素早い攻撃、絆を継いだ世代は援護攻撃）

### 英雄の残照（引き戻し5G）
- 英雄連合終了後に発動
- 「絆の継承」を選んでいた場合は**確定発動**
- 奇数図柄揃いで世代AT再突入

## 決戦AT「世代の決着」

### 発動条件（3条件すべて必要）
1. 宿敵弱体化ゲージ MAX
2. 皇帝の力ストック獲得
3. 継承コンプリート（速さ・深さ・絆の3種すべて選択）

### 性能・演出
- 純増：**8.0枚/G**
- 演出：歴代全世代の英雄が集結し、宿敵イグナールとの最終決戦
- 「積み上げた意志が1つの光になる」クライマックス演出
- 1000年ぶりの宿敵討伐 → 感動の幕引き

### 出玉設計
| 状態 | 期待枚数 |
|---|---|
| 通常AT（1〜2世代） | 300〜400枚 |
| 英雄連合（3世代ループ） | 1,000〜1,500枚 |
| 決戦AT | 1,500枚以上 |
| **MY目安（1日全部込み）** | **約3,500枚** |
