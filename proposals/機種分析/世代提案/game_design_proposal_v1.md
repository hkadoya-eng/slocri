# スロット新機種 ゲーム性提案書
### 〜173週分の実稼働データ分析から導いた「長期稼働する設計の法則」〜

---

## はじめに：なぜこの提案書を作ったか

「初週は大賑わいなのに、3ヶ月で誰も打っていない台」——この問題がずっと気になっていました。
実稼働データ（453機種・173週分）を分析したところ、**長期稼働できる台とできない台の違いが数値で明確に出ました**。
そこから逆算して、「こんなゲーム性ならどうだろう？」という提案をまとめました。

---

## SECTION 1｜データが教えてくれた「長期稼働の法則」

### 発見した指標：変動係数（CV）= 設定依存度

週ごとのアウトのバラつきを「変動係数（CV）」として計算し、**後半維持率（13週以降の稼働/初期稼働）との相関を取ったところ、r = -0.913 という超強い負の相関が出ました。**

> **「CVが低いほど、長期的に稼働が維持される」**
> n=130機種（ジャグラー系除く・30週以上のデータ）

| CV値の目安 | 意味 | 後半維持率の傾向 |
|-----------|------|----------------|
| CV < 0.2 | 設定に関わらず安定稼働 | **70〜90%台** |
| CV 0.3〜0.5 | 設定依存が中程度 | 40〜65%台 |
| CV > 0.6 | 高設定のときだけ爆発 | **20〜35%台** |

---

### 長期稼働できた機種 vs できなかった機種の比較

| 機種 | 稼働週数 | 平均稼働率 | CV | 後半維持率 |
|------|---------|-----------|-----|----------|
| **L東京喰種** | 63週 | **182%** | **0.18** | **73.7%** |
| **LスマスロモンキーターンV** | 124週 | **144%** | **0.23** | **68.2%** |
| **LディスクアップULTRAREMIX** | 65週 | **146%** | **0.25** | **61.9%** |
| Sカバネリ（旧型） | 173週 | ※前半213% | 0.51 | 41.4% |
| L番長４ | 104週 | ※前半187% | 0.68 | 29.6% |
| Lスマスロ北斗の拳 | 159週 | ※前半257% | 0.43 | 42.1% |

※稼働率 = 機種アウト ÷ 全体平均アウト × 100%（100%が平均、高いほど稼働上位）

> **北斗の拳やカバネリは「初週から圧倒的」だったが、長期的には設定を下げると急落した。**
> 一方、東京喰種とモンキーターンVは「高設定の週も低設定の週もあまり変わらず」継続的に高稼働。

---

### なぜCVが低いと長続きするのか？

**CV低い機種が共通して持っている設計：**

- **東京喰種（CV=0.18）**：赫眼状態・喰種対決・引き戻し前兆 = **設定1でも体験できる盛り上がり**
- **モンキーターンV（CV=0.23）**：競艇レースの映像演出・V入賞の緊張感 = **設定に関係なく誰でも体験できる感動**
- **ディスクアップULTRAREMIX（CV=0.25）**：技術介入の面白さ = **腕が上がる楽しさは設定関係なし**

**CV高い機種が陥っているパターン：**
- 高設定時：ボーナス連発・上乗せ祭り → 大盛り上がり
- 低設定時：ゲームが全然動かない → 「つまらない台」として印象が固定
- → ホールが設定を下げた瞬間に稼働崩壊

---

### 結論：「打ちたい気持ち」と「やめにくさ」は別物だった

```
やめにくさ  ＝ 今のセッションを続けたい（天井・残G数・損失回避）
打ちたい気持ち ＝ また来週ここに打ちに来たい（ゲームへの愛着・達成欲求）
```

**長期稼働するのは「やめにくさ」ではなく「打ちたい気持ち」を生む機種。**
そして「打ちたい気持ち」は、**設定に依存しないゲーム体験の完成度**から生まれる。

## SECTION 2｜提案するゲーム性コンセプト

### コンセプトネーム（仮）：「**進化するバトル型AT**」

データから逆算した設計原則：
1. **AT中の演出・バトルは設定非依存で面白い**（低設定でも体験の質が変わらない）
2. **設定差はAT突入頻度に集中**（設定が高いほど当たりやすい、でも当たったら同じ体験）
3. **セッションごとに「今日の達成感」が残る**（打つたびに前進する感覚）

---

### ゲームフロー

```
【通常時：挑戦ゾーン】
│
│  通常リール演出：敵のシルエットが徐々に明確化
│  50G〜300G：内部モードにより挑戦権の重さが変化（設定差あり）
│  レア役・ゾーン到達 → CZ「激突バトル」（30G）
│
├─ CZ失敗 → 「バトルポイント（BP）」として蓄積（持ち越し可）
│           BP MAXで天井CZへ（設定差なし・全員いつかは突入）
│
└─ CZ成功 → AT「BURST CHAIN」突入
             ─────────────────────────────
             【AT：BURST CHAIN】 純増3.8枚 / 1セット40G
             ─────────────────────────────
             ├ 【毎G】小役でポイント蓄積 → 50ptで「上乗せ抽選」
             │         ↑ここは設定差なし。押し順・引きで決まる自力感
             │
             ├ 【10G毎】バトルフェーズ（全3段階）
             │   1段階目：ザコ戦（ほぼ勝てる・達成感のチュートリアル）
             │   2段階目：中ボス戦（勝率60〜70%・緊張感）
             │   3段階目：ボス戦（勝率40〜50%・クライマックス）
             │   ★バトル勝敗は「小役成立パターン」で決まる→完全自力感
             │   ★設定は関係しない（どの設定でも同じ勝率）
             │
             ├ ボス撃破 → セット上乗せ（+20〜60G）＆「継続演出」
             │            「また来週も来たい」演出（エンディングへの予告）
             │
             └ ボス敗北 → セット終了、次回への引き戻し抽選
                          「あと一歩だった悔しさ」 → リベンジ欲求

【上位AT：CHAIN BURST MAX】（条件：ボス連続撃破3回）
│  純増5.2枚 / 上乗せフリー状態
│  特別BGM・特別演出（IP最高潮）
│  ここだけ全設定で同じ確率で突入可能（技術介入・引き次第）
```

---

### 設計の核心：「なぜ低CVになるのか」

**AT中のバトル結果を「小役成立パターン」で決定する理由：**

- 小役は設定に関係なく確率がほぼ同じ → どの設定でも同じバトル体験
- プレイヤーは「自分の引きで勝敗が決まった」と感じる → デキレ感ゼロ
- 勝った時の喜び・負けた時の悔しさが毎セッション発生 → リベンジ来店

**設定差をAT頻度に集中させる理由：**

- 設定6：天井が浅い・CZ確率高い → 頻繁にATに入れる
- 設定1：天井が深い・CZ確率低い → 一発当たるまでが長い
- でも「ATに入ったらどの設定でも同じゲームが楽しめる」

→ 設定6狙いのユーザーは「今日は高設定だ！」と楽しみ、
　 低設定ユーザーも「やっと来た！バトルだ！」で盛り上がる。
　 **どちらも「打ってよかった」体験が残る。**

## SECTION 3｜気になるポイントと論点

**この提案で議論したい点：**

### Q1: バトル勝率を「設定非依存」にすることへの懸念は？
設定差がAT頻度のみになるため、設定6の魅力をどう伝えるかが課題。
→ 「設定6は当たりやすい＝バトルを何回も楽しめる」という価値提案でどうか。

### Q2: バトルフェーズの勝率バランスはどこが適切か？
- ボス戦40〜50%は「勝っても負けても納得感がある」ラインのつもり。
- 勝率が高すぎると達成感が薄い、低すぎると離脱する。

### Q3: IPとの親和性は？
このゲームフローは「バトル系IP」との相性が良い設計。
たとえば格闘・スポーツ・ダンジョン系。逆に「日常系」とは合いにくい。

### Q4: セット完結型 vs 継続ループ型、どちらが「打ちたい気持ち」に有効か？
本提案はセット完結型（40G×複数セット）を採用。
ループ型（沖ドキ系）はCV低いが「やめにくさ」寄り。あえてセット完結にした。
